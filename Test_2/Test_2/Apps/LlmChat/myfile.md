# 고양이 택배부 (Cat Delivery Service)

### **게임 제목**

고양이 택배부 (Cat Delivery Service)

**장르**

2D 캐주얼 퍼즐 + 방치형 수집 게임 (모바일 세로형)

**타겟**

10대 후반 ~ 30대 여성 및 힐링 게임 좋아하는 모든 연령

**한 줄 요약**

고양이들이 자전거·드론·로켓까지 타고 택배를 배달하며 마을을 키우는 귀여운 방치형 게임

**핵심 재미 요소**

1. 귀여운 고양이 100종+ 수집 & 코스튬
2. 30초마다 한 번씩 택배 배달 → 자동 수익 발생 (방치형)
3. 간단한 슬라이드 퍼즐로 배달 경로 최적화 → 수익 2~5배 증가
4. 배달 성공 시 마을이템(나무, 건물, 랜드마크)으로 내 마을 꾸미기

**게임 흐름 (3분 플레이 기준)**

1. 게임 실행 → 고양이들이 이미 열심히 택배 배달 중 (오프라인 수익 정산)
2. 화면에 쌓인 택배 더미를 손가락으로 슬라이드해서 최적 경로 연결 (퍼즐)
3. 배달 성공 → 돈 + 마이템 폭발
4. 고양이 레벨업 & 새 고양이 뽑기 & 마을 꾸미기
5. 앱 종료 → 다시 방치

**수익화**

- 광고: 오프라인 수익 2배, 새 고양이 즉시 획득 (보상형 광고)
- 인앱: 고양이 뽑기 10회 패키지, 영구 2배 부스터 등 (강제 없음)

**차별점**

“방치형인데 퍼즐이 있다” + “진짜 귀여운 고양이들이 움직인다”

기존 방치형의 지루함은 퍼즐로, 퍼즐 게임의 피로는 방치로 해결

**개발 규모**

팀 3~4명 기준 4~5개월 (Unity 2D, 이미 많은 무료 고양이 에셋 활용 가능)

**목표**

출시 3개월 내 대한민국 구글 플레이 캐주얼 랭킹 20위권 진입
